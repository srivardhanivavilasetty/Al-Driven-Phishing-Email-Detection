About the Project

This application uses Natural Language Processing and machine learning to analyze email messages, derive structured metadata features, and classify each email as phishing or legitimate.

Key components
  • Text cleaning, tokenization, and lemmatization with NLTK.
  • TF-IDF vectorization for email subjects and bodies.
  • Custom metadata extraction for URLs, suspicious keywords, and urgency patterns.
  • Model comparison with Logistic Regression, Naive Bayes, Random Forest, and MLP.
  • Historical analysis storage in MySQL.
